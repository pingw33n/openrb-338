# ida/

The IDA databases of the original program: `Rebirth.exe.i64` (the UI, song loading, the export
driver, the RBM container) and `ReBirth.dll.i64` (the engine). They are made from Propellerhead's
copyrighted files (see `original/README.md`), so they are **not in git**: everything in this
folder except this README is ignored. They are local to the user's machine. Agents copy one to
their scratchpad and open the copy through the idalib MCP tools, read-only (backlog doc-001).

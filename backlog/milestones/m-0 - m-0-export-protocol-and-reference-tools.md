## Description

Make the original ReBirth 2.01 produce deterministic, reproducible reference renders of .rbs songs on the Windows test machine, and build the tools around them: test-machine setup, the reverse-engineered export and song-load protocol, an offline host for the original engine DLL, an .rbs writer for diagnostic songs, a render comparator, table and state dumps, and the reference corpus. Done when the same song renders byte-identically every time from the original and the corpus of references is committed.
Background: docs/initial_investigation.md (sections 3, 5.2, 9 and 10).
